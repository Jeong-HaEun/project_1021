## 2026-10-15 · 상단 혜택 안내 바와 메인 히어로 문구

### 바꾼 것
| 위치 | 이전 (원본 cecith.kr) | 변경 |
|---|---|---|
| 상단 안내 바 | "회원가입 즉시 4만원 웰컴쿠폰팩" | "워터락 퍼스트 세럼 30ml ~~15,000원~~ → 8,900원 · 배송비 별도 · 공식몰 ↗" |
| 히어로 제목 | 영문 슬로건 "Own Your Natural Glow" 중심 | "약사가 설계한 / 매일의 피부장벽 루틴" (영문 슬로건은 작은 보조 요소로 유지) |
| 히어로 설명 | — | "피부장벽을 중심으로, 매일의 스킨케어에 필요한 제품과 사용법을 살펴보세요." |
| 히어로 버튼 | "혜택 보러가기" | "워터락 세럼 자세히 보기 ↗" + "워터락 퍼스트 세럼 150ml · 공식몰로 이동합니다" |

### 원칙
1. **한국어로 브랜드의 분야와 특징을 구체적으로 전달한다.**
   영문 슬로건만으로는 "어떤 분야의, 무엇이 다른 브랜드인지"가 드러나지 않는다. 원본 메타 설명("약사가 설계한 피부장벽 루틴 솔루션")을 바탕으로 분야(피부장벽)와 특징(약사 설계, 매일의 루틴)을 제목에 넣었다.
2. **상단 혜택은 상품·용량·가격을 함께 보여준다.**
   "4만원 쿠폰팩"은 무엇을 얼마에 살 수 있는지 알려주지 않는다. 구체적인 상품명·용량·소비자가·판매가를 보여주고, 8,900원이 최종 결제금액으로 오해되지 않도록 "배송비 별도"를 붙였다.
3. **버튼이 약속하는 정보와 도착 페이지의 내용을 일치시킨다.**
   "혜택 보러가기"가 연결되던 일반 워터락 세럼(150ml) 상세에는 별도 할인이 없다. 버튼 문구를 도착 페이지 내용("워터락 세럼 자세히 보기")에 맞추고, 상단 바의 30ml 미니 세럼과 헷갈리지 않도록 용량을 함께 적었다.
4. **구매 전환 상승은 검증할 가설이며, 입증된 성과가 아니다.**
   이 변경으로 클릭·구매가 늘 것이라는 기대는 가설이다. 실제 효과는 측정(예: 안내 바·히어로 버튼 클릭 이벤트)으로 확인해야 하며, 발표 자료에도 "개선 가설"로 표현한다.

### 확인한 사실 (공식몰, 2026-10-15)
- 미니 세럼(product_no=20): 상품명 "[WELCOME] 워터락 퍼스트 세럼 30ml", 소비자가 15,000원, 판매가 8,900원, 배송비 3,000원(5만원 이상 무료)
- 일반 세럼(product_no=11): "워터락 퍼스트 세럼 150ml", 33,000원, 할인 없음
- 원본 메인 메타 설명: "약사가 설계한 피부장벽 루틴 솔루션. …"

### 표시하지 않은 것 (확인되지 않음)
- 신규가입·첫구매 한정 여부: 상품명의 [WELCOME] 표기와 원본 메뉴명 "첫구매특가"만 있고, 상세 화면에 조건 안내 문구가 없다.
- 구매 수량 제한: 페이지 코드상 최대 수량 1로 설정돼 있으나 화면 안내 문구가 없다.
- 쿠폰 적용 조건: 해당 상품에 대한 안내가 없다.

## 2026-10-15 · 메인 본문 순서: 구매 전 궁금증 순서 (설계 가설)

### 순서
① 히어로(어떤 브랜드인지) → ② 대표 제품 비교 → ③ 사용 후기 → ④ 성분과 특징 → ⑤ 아침·저녁 루틴 → ⑥ 자주 묻는 질문 → ⑦ 브랜드 이야기

### 원본 대비 (공식몰 메인, 2026-10-15 확인)
| 원본 순서 | 이번 순서 | 바꾼 이유 |
|---|---|---|
| 히어로 → ALL PRODUCTS → Barrier Guide → Routine Guide → Founder's Note → Real Review(맨 아래) | 위 ①~⑦ | 후기를 제품 바로 다음으로 올리고, 제품 고를 근거·사용법·질문을 브랜드 이야기보다 앞에 둠 |
| ALL PRODUCTS: 가격만 표시 | 역할·용량·가격 비교, 미니는 같은 카드 안에서 구분 | 무엇에 쓰는 제품인지 먼저 알 수 있게 |
| Routine Guide: 탭 3개(링크 없음, 내용 없음) | 확인된 단계만 + 제품 연결 | 설문 없이 사용 단계 확인 |
| Barrier Guide 영역: 가이드 글 대신 상품 노출 | 질문 중심 FAQ + 실제 가이드 글 1편 | 고객 질문 기준 정리 |

### 원칙
- 후기는 실제 후기만: 제품명·가린 작성자·작성 시점·구매 인증·출처·확인일 표시. 후기별 별점은 확인되지 않아 표시하지 않고, 상품 평균 별점·후기 수만 출처와 함께 표시. 발췌는 원문 표기 그대로, 생략 위치에 "…".
- 의학적 효과를 말하는 후기·문구는 고르지 않음 (CLAUDE.md 표현 규칙). 약사 이력을 효과의 보증처럼 쓰지 않음.
- **공식몰(cecith.kr)로 가는 링크·버튼은 두지 않음** — 브랜드 허락이 없는 포트폴리오이므로 기본 조건. 모든 버튼은 사이트 안 페이지(제품·가이드·브랜드)로 연결하고, 그 내용은 이후 채움. 테스트로 공식몰 주소가 들어가지 않게 막음.
